### Overview & Lab Instructions
This folder documents the practice workflows on **Software Testing Tools and Defect Remediation** using modern AI-assisted engineering ("vibe coding") to locate bugs, generate patches, and verify test cases.

### Software Testing Methodology & Protocol
1. **Target Application:** Individual game application code / microservice utility with 4 test cases.
2. **Testing Lifecycle:**
   - **Step 1 — Static & Dynamic Analysis:** Run the baseline test suite; identify failing test cases and stack traces.
   - **Step 2 — Root Cause Analysis (RCA):** Isolate off-by-one errors, unhandled null pointers, or concurrency race conditions.
   - **Step 3 — Vibe Coding & Patch Generation:** Use targeted AI prompts to generate surgical code fixes.
   - **Step 4 — Regression Testing & Verification:** Re-execute all 4 test cases to ensure 100% pass rate with zero regressions.
   - **Step 5 — Defect Logging:** Document bug ID, severity, reproduction steps, and resolution in Jira (`BUG-001`, `BUG-002`).
